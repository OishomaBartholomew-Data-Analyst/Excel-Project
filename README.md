# EXCEL DATA CLEANING PROJECT
### Data Cleaning and Preparation Using Microsoft Excel
## Project Overview
### This project focuses on cleaning and preparing a raw dataset using Microsoft Excel to make the data accurate, consistent, organized, and ready for analysis.
Data cleaning is an important stage in the data analytics process because raw datasets often contain errors, missing values, duplicate records, inconsistent formatting, and irrelevant information.

In this project, I used Microsoft Excel to identify and correct data quality issues and transform the raw dataset into a clean and structured format for further analysis.


## Project Objectives
### The main objectives of this project are to:
- Identify and remove duplicate records.
- Detect and handle missing values.
- Correct spelling errors and inconsistent entries.
- Standardize text formatting
- Ensure consistent date formats.
- Identify and correct data entry errors.
- Organize the dataset into a structured table.
- Prepare the cleaned dataset for data analysis and visualization.

## Data Cleaning Process

1: Import the Dataset

.Open Microsoft Excel.

.Load the raw dataset.

.Review the columns and rows.

.Understand the structure of the dataset.

Step 2: Identify Duplicate Records

.Select the dataset.

.Navigate to the Data tab.

.Select Remove Duplicates.

.Choose the appropriate columns.

.Remove duplicate records where appropriate.

Step 3: Handle Missing Values

.Identify blank cells.

.Use filters to locate missing information.

.Determine whether to fill, replace, or remove missing values based on the dataset.

.Avoid making assumptions when filling missing information.

.Step 4: Remove Extra Spaces

.Use the TRIM function to remove unnecessary spaces.

.Formula:

=TRIM(A2)

Step 5: Standardize Text Formatting

Use the following Excel functions:

.UPPER() – Converts text to uppercase.

.LOWER() – Converts text to lowercase.

.PROPER() – Capitalizes the first letter of each word.

.Step 6: Correct Date Formatting

.Identify inconsistent date entries.

.Convert dates into a consistent format.

.Ensure Excel recognizes the values as dates.

Step 7: Correct Inconsistent Entries

.Use Find and Replace.

.Correct spelling mistakes.

.Standardize repeated category names.

.Check for incorrect data entries.

Step 8: Validate the Cleaned Dataset

.Review the cleaned data.

.Check for remaining duplicates.

.Confirm that missing values have been handled.

.Verify that dates and numerical values are consistent.

.Ensure the dataset is ready for analysis.
## Expected Results
